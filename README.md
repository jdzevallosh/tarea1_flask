# Tarea 01 - Aplicación Web con Flask

Aplicación web desarrollada con Flask y SQLite que implementa un CRUD completo de usuarios, endpoints API que retornan formato JSON y búsqueda dinámica en tiempo real utilizando HTMX.

## Requisitos y Tecnologías
- Python 3.12+
- Flask
- SQLite3
- HTMX (vía CDN)
- UV (Gestor de paquetes)
